# BUG-002 — Missing Input Validation for Category Creation (Empty / Whitespace Names Allowed)

**Bug ID:** BUG-FR14-002  
**Feature:** FR-14 — Category Management (CRUD)  
**Date Reported:** 2026-07-07  
**Reported By:** AI (Antigravity) via EXEC-01  
**Linked Test Cases:** TC-DT-003  
**Severity:** Medium  

---

## Title

Category creation input allows saving empty strings or whitespace-only strings as category names.

---

## Environment

| Item | Value |
|------|-------|
| Frontend | http://localhost:5174 (Admin React/Vite) |
| Backend | http://localhost:3000 (Node.js/Express + SQLite) |
| Browser | Chromium (Playwright headless) |
| OS | Windows |
| Admin | `admin@eshop.com` / `Admin123!` |

---

## Preconditions

1. Admin is authenticated and logged into the Admin Panel.
2. Admin is on the Category page.

---

## Steps to Reproduce

1. Leave the "Tên danh mục mới" text input blank (or enter spaces `"    "`).
2. Click the "Thêm mới" button.
3. Observe the Category list.

---

## Expected Result

- Submission is blocked on the client side or rejected by the backend server with an error code (e.g. `400 Bad Request` with message "Vui lòng nhập tên danh mục").
- No empty/whitespace category record is inserted into the database.

---

## Actual Result

- The category is successfully created.
- The input field is cleared.
- A new row appears in the Category table with a blank text value.

## Severity Assessment

**Medium**

- **Functional impact:** Users can inadvertently corrupt the category structure by adding empty records. These records show as blank cells in the product editor and storefront categories filter, which disrupts the user experience.
- **Workaround:** None available besides manually identifying the ID and invoking the DELETE API.

**Severity:** Medium

The category creation page does not validate the new category name input. Submitting a blank string or a series of whitespace characters results in an empty category record being successfully saved to the database.

1. Log in as admin and go to the "Danh mục" tab.
2. Do not type anything in the input field, and click "Thêm mới".

Validation blocks empty name submission, alerting "Vui lòng nhập tên danh mục".

### Actual Behaviour
The empty name category is saved to database.
