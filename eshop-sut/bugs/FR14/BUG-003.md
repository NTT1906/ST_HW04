# BUG-003 — Missing Uniqueness Check for Category Names (Duplicate Categories Allowed)

**Bug ID:** BUG-FR14-003  
**Feature:** FR-14 — Category Management (CRUD)  
**Date Reported:** 2026-07-07  
**Reported By:** AI (Antigravity) via EXEC-01  
**Linked Test Cases:** TC-DT-004  
**Severity:** Medium  

---

## Title

Category creation allows saving duplicate category names, violating the uniqueness constraint.

---

## Environment

| Item | Value |
|------|-------|
| Frontend | http://localhost:5174 (Admin React/Vite) |
| Backend | http://localhost:3000 (Node.js/Express + SQLite) |
| Browser | Chromium (Playwright headless) |
| OS | Windows |
| Admin | `admin@eshop.com` / `Admin123!` |

---

## Preconditions

1. Admin is authenticated and on Category page.
2. Category `"Điện thoại"` already exists in database.

---

## Steps to Reproduce

1. Type `"Điện thoại"` in the "Tên danh mục mới" text input.
2. Click the "Thêm mới" button.
3. Observe the Category list.

---

## Expected Result

- Submission is blocked on the client side or rejected by the backend server with an error code (e.g. `400 Bad Request` with message "Tên danh mục đã tồn tại").
- No duplicate category record is inserted.

---

## Actual Result

- A second category named `"Điện thoại"` is created successfully.
- The table displays two distinct category rows with the exact same name `"Điện thoại"` but different IDs (e.g. `#1` and `#6`).

## Severity Assessment

**Medium**

- **Functional impact:** Duplicate category names create user confusion in the product editor and storefront navigation filters. There is no easy way to distinguish between two categories sharing the same name in dropdown selection menus.
- **Workaround:** None.

## [BUG] FR-14: Category creation allows duplicate category names

**Severity:** Medium  
**Feature:** FR-14 — Category Management  
**Endpoint:** POST /api/categories  

### Description
The category management page and backend service do not check for name uniqueness before creating categories. An administrator can submit duplicate category names, which bypasses validation and writes multiple identical category rows into the database.

### Steps to Reproduce
1. Log in as admin and go to the "Danh mục" tab.
2. Type an existing category name (e.g. "Điện thoại") in the input field.
3. Click "Thêm mới".
4. Two categories with the name "Điện thoại" are visible in the table.

### Expected Behaviour
Validation blocks duplicate names, alerting "Tên danh mục đã tồn tại".

### Actual Behaviour
Duplicate is accepted and saved.

- Screenshot: TC-DT-004-after.png
